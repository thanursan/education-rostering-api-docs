# Education Rostering API

An independent API documentation sample for a fictional education rostering service.

This project demonstrates technical writing and API documentation practices through a hypothetical REST API designed for managing educational resources and asynchronous rostering operations.

## Documentation

[View the documentation site](https://thanursan.github.io/education-rostering-api-docs/)

The documentation covers:

- Getting started and API conventions
- OAuth 2.0 client credentials authentication
- Teacher, student and class endpoints
- Asynchronous rostering jobs and callbacks
- Error responses and handling

## Technical details

- REST API design
- JSON request and response formats
- OAuth 2.0 authentication
- Markdown documentation
- Zensical
- Git and GitHub
- GitHub Actions and GitHub Pages

## Local development

Install Zensical, clone the repository and navigate to the project directory.

Start the local documentation server:

```bash
zensical serve
```

The documentation is served locally at `http://localhost:8000`.

## Project scope

The API is fictional and has not been implemented. All endpoints, payloads and responses are illustrative and intended to demonstrate API documentation practices.
