# Education Rostering API

The Education Rostering API is a fictional REST API for synchronising school data with an education platform.

It provides endpoints for managing teachers, students and classes, plus an asynchronous operation for submitting larger rostering changes as a job.

!!! info "Documentation sample"
    This is an independently designed API documentation sample. The service and endpoints are fictional. No live API is available.

## What you can do

- Create, retrieve, update and delete teachers.
- Create, retrieve, update and delete students.
- Create, retrieve, update and delete classes.
- Submit a batch of rostering changes and track its execution.

## Before you begin

You'll need API client credentials issued by the fictional service administrator. The API uses OAuth 2.0 Client Credentials and accepts and returns JSON.

Start with [Get started](get-started.md), then review [Authentication](authentication.md) before making requests.

## API at a glance

| Property | Value |
